💅 Проєкт: Beauty Nails ERP – Повний План Розробки
🎯 Візія Проєкту
Створити інтелектуальну платформу для керування салоном краси, де клієнт отримує бездоганний досвід запису (UX), а власник (адмін) — повний контроль над розкладом, фінансами та персоналом.

🛠 Поточний Стан (MVP 1.0)
[x] Налаштовано Next.js, Tailwind CSS та Prisma.

[x] База даних Neon (PostgreSQL) підключена.

[x] Авторизація (Admin/Client) працює.

[x] Базовий API для записів створений.

[x] Первинні інтерфейси Dashboards готові.

🗺 Дорожня карта розробки (Milestones)

1. Фундамент: Розширена База Даних та Ролі
   [ ] Майстри (Staff): Створити модель Employee. Додати поля: ім'я, фото, рейтинг, опис.

[ ] Графік роботи: Додати таблицю WorkingHours. Можливість вказати вихідні (наприклад, неділя) для кожного майстра.

[ ] Валюта: Змінити тип даних ціни на Float та встановити дефолтну валюту — Złoty (zł).

[ ] Статус Online: Додати поле lastSeen в модель User для відстеження активності в реальному часі.

[ ] Аватари: Налаштувати логіку: якщо фото немає — відображати стилізовані SVG-іконки дівчат (випадково або за вибором).

2. Клієнтський шлях: "Magic Booking Flow 2.0"
   [ ] Інтерактивний Календар:

[ ] Заміна списку на повноцінну сітку місяця.

[ ] Блокування минулого: Заборонити клік на дати, що вже минули.

[ ] Динамічні Слоти (Time Selection):

[ ] При виборі дати календар плавно зникає (анімація).

[ ] Генерація годин з інтервалом 2 години (09:00, 11:00, 13:00...).

[ ] Блокування часу: Якщо сьогодні 14:00, клієнт не може бачити слоти на 09:00 та 11:00.

[ ] Вибір Послуги та Майстра:

[ ] Після вибору часу з'являється меню послуг (Манікюр, Педикюр...).

[ ] Вибір конкретного майстра (Анастасія, Аня...) з відображенням їхнього рейтингу.

[ ] Екран Перевірки (Summary):

[ ] Фінальна картка: "23 число, 15:00, Манікюр, Майстер Анастасія".

[ ] Кнопка "Підтвердити" (відправка адміну).

[ ] Кнопка "Змінити" (повернення на конкретний крок: зміна тільки дати або тільки послуги).

3. Адмін-панель: Центр Керування та Фінанси
   [ ] Smart Dashboard:

[ ] Динамічний графік прибутку: сумуються тільки Confirmed записи.

[ ] Бюджет зростає в реальному часі при зміні статусу запису.

[ ] Керування Розкладом:

[ ] Кнопка "Скасувати" (Decline): при натисканні сума автоматично віднімається від статистики.

[ ] Блокування (ЧП): Можливість адміну виділити дату або годину як "Недоступну" (закреслюється для клієнтів).

[ ] Модуль Акцій:

[ ] Інтерфейс для створення карток акцій (текст + знижка).

[ ] Відображення цих карток у клієнта в правій колонці.

   [ ] Сповіщення (Notifications):

5. Особистий кабінет (Profile Management)
   [ ] Клієнт: Редагування імені, телефону, завантаження аватара.

🛠 Технічні виклики (Technical Notes)
Інтервали часу: Логіка перевірки зайнятих слотів має враховувати тривалість послуги (2 години).

Синхронізація графіка: Якщо адмін заблокував час, API не має віддавати цей слот клієнту.

Złoty conversion: Всі розрахунки проводити в копійках (integer), щоб уникнути помилок з плаваючою комою у фінансах.

💡 Мої роздуми щодо твоїх ідей:
Чат та Online-статус: Це дуже круто. Ми можемо реалізувати це через "Polling" (запит кожні 30 секунд) або "WebSockets" (якщо захочемо миттєво). Для початку зробимо просту перевірку lastSeen в базі. Якщо людина була активна останні 5 хвилин — ставимо зелений кружечок.

Блокування дати (ЧП): Я пропоную зробити в адмінці "Режим Бога": ти тиснеш на будь-яку годину в календарі, і вона стає червоною. Система просто створює технічний запис на твоє ім'я, і цей час автоматично зникає у клієнтів.

Зміна аватарки: Використаємо хмарне сховище (наприклад, Uploadthing або Cloudinary), щоб твій сервер не перевантажувався картинками.

Майстер Анастасія (MVP): Ми зробимо так, що ти — головний майстер за замовчуванням. Але структура вже буде готова до розширення ( scalability).
